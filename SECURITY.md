# Security Policy

## Supported versions

Security fixes are applied to the latest release on the `main` branch.

## Reporting a vulnerability

Thanks for helping keep Zelvior Vibecoding Mega Skill and its users safe.

Please **do not** open a public issue for security vulnerabilities. Instead, report them privately:

1. Use GitHub's **Security** tab → **Report a vulnerability** for this repository, or
2. Open a private security advisory via the repository's security advisories page.

When reporting, please include:

- A description of the vulnerability and its impact.
- The steps to reproduce (a minimal example is ideal).
- Any suggested fix or mitigation, if you have one.

We will acknowledge your report within a few business days and keep you updated on the resolution. We ask that you do not exploit a vulnerability beyond what is necessary to demonstrate it, and give us reasonable time to address it before any public disclosure.

## Scope

This policy covers vulnerabilities in the skill's scripts (`scripts/audit.py`, `scripts/compat.py`, and the `zelvior-craft` Node scripts) and the guidance the skill provides. Issues in the websites users build with the skill should be reported to the owners of those sites.
