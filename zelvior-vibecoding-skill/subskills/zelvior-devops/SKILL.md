# Zelvior DevOps Subskill

Ship safely with infra as code, staged deploys, and full observability. Read `../../references/10-devops-sre.md` for full detail.

## Must-have

CI/CD, Docker, Kubernetes, Helm charts, Terraform, infrastructure as code, build caching, dependency management, blue-green, canary, and rolling deploys, one-command rollbacks, feature flags, kill switches, health checks, liveness and readiness probes, autoscaling, horizontal and vertical scaling, CDN, edge caching, cache invalidation, monitoring, logging, distributed tracing, metrics, incident response, on-call, postmortems, memory leak and GC monitoring, thread safety, backpressure.

## Rules

- No manual production deploys. No click-ops in production.
- Every deploy has health checks, monitoring, alerts, and a tested rollback.
- Alert on symptoms (latency, errors, saturation), not causes.
