# Zelvior UI

A focused interface design knowledge set. It routes interface styling work to the
right subskill so the right rules are loaded, instead of one oversized doc.

Load the subskill that matches the task. When several apply (e.g. "build a
card with good colors and spacing"), load all relevant ones.

## Routing

| Task | Subskill |
|------|----------|
| Spacing, padding, margin, layout, whitespace, shadows, hierarchy, responsive design | `subskills/zelvior-ui-principles/SKILL.md` |
| Picking colors, hex/HSL values, color scales, Tailwind theme, CSS custom properties, semantic colors | `subskills/zelvior-ui-palettes/SKILL.md` |
| Choosing font-family, typeface, font pairing, font stack, Google Fonts, weights | `subskills/zelvior-ui-fonts/SKILL.md` |
| Building a specific component (button, form, table, card, modal, nav, alert, dropdown, etc.) | `subskills/zelvior-ui-components/SKILL.md` |
| Accessibility, a11y, WCAG, ARIA, screen reader, keyboard nav, focus, contrast, alt text, target size | `subskills/zelvior-ui-a11y/SKILL.md` |

## How to use

1. Read this router and pick the subskill(s) that match the task.
2. Load the subskill file and follow its rules.
3. When a task spans domains (a styled, accessible, on-brand component), load
   every relevant subskill and reconcile their rules — accessibility and
   contrast rules win over pure aesthetics.

The five subskills are standalone: each can be loaded on its own for a single
domain, or together for a full UI pass.
