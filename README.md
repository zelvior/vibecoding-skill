# Zelvior Vibecoding Mega Skill

A senior-level mega skill for building production websites and apps that pass a strict Audityxe-style audit.

## What is inside

- `zelvior-vibecoding-skill/SKILL.md`: the mega skill. Design patterns, backend, security, SEO, performance, accessibility, CRO, DevOps, and the definition of done.
- `zelvior-vibecoding-skill/references/`: 12 deep-dive guides, including the full 236-test audit checklist across 32 modules.
- `zelvior-vibecoding-skill/subskills/`: 6 standalone subskills (design, backend, security, SEO/performance, DevOps, audit).
- `zelvior-vibecoding-skill/scripts/audit.py`: local audit script for the highest-signal checks.
- `zelvior-vibecoding-skill/assets/`: robots.txt, llms.txt, security.txt, sitemap.xml, and 404 templates.

## Quick start

```bash
python3 zelvior-vibecoding-skill/scripts/audit.py https://example.com
python3 zelvior-vibecoding-skill/scripts/audit.py ./dist/index.html
```

Read `zelvior-vibecoding-skill/SKILL.md` first, then load only the reference files you need.
